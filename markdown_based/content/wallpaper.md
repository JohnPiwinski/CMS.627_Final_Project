# Wallpaper Symmetries {#wallpaper-symmetries}

## Exploring wallpaper symmetries {#wallpaper-exploration}
### Repeating a tile {#wallpaper-translation}
::scene[wallpaper-playground]

:::narration[wallpaper-translation-intro]
A wallpaper pattern repeats in two independent directions. Try using the translation tool from our lattice tutorial. Choose two lattice points and watch the pattern move. What changes, and what stays the same?
:::
::pause

### Rotations and reflections {#wallpaper-rotation-reflection}
::scene[wallpaper-playground]

:::narration[wallpaper-rotation-reflection-intro]
Translations are not the only symmetries a wallpaper can have. Try rotating the pattern around different points. Then try reflecting it across different lines. Can you find transformations that leave the entire colored pattern unchanged?
:::
::pause

### Glide reflections {#wallpaper-glide-reflection}
::scene[wallpaper-playground]

:::narration[wallpaper-glide-intro]
Sometimes reflecting a wallpaper does not give us the original pattern. But what happens if we reflect it and then slide it along the reflection line? This combination is called a glide reflection. Try to find one that preserves this wallpaper.
:::
::pause

### Orbits and symmetry centers {#wallpaper-orbits}
::scene[wallpaper-playground]

:::narration[wallpaper-orbits-intro]
Choose a point on the wallpaper. Where can the symmetries of the wallpaper move that point? All the points we can reach form its orbit. Try reaching some of them using translations, rotations and reflections.
:::
::pause

## The seventeen wallpaper groups {#wallpaper-groups}
### Explore the abstract patterns {#wallpaper-group-gallery}
::scene[wallpaper-gallery]

:::narration[wallpaper-gallery-intro]
There are seventeen types of wallpaper symmetry groups. Each is distinguished by the kinds of symmetries it has and how those symmetries are arranged. Explore these examples using the tools you already know. Look for differences between patterns that seem similar at first.
:::
::pause

### Match the decorative wallpapers {#wallpaper-matching}
::scene[wallpaper-matching]

:::narration[wallpaper-matching-intro]
Wallpaper groups appear in many different decorative designs. Two patterns can look quite different and still have the same type of symmetry. Match each decorative wallpaper to the abstract pattern with the same wallpaper group. You can return to the symmetry tools whenever you need to investigate a pattern.
:::
::pause
