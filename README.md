# Interactive Artin Algebra

**Play the website:** [Interactive Artin Algebra on GitHub Pages](https://johnpiwinski.github.io/CMS.627_Final_Project/)

The site is built from [`markdown_based/`](markdown_based/), which contains the Emmy Noether’s Office game and its Chapter Zero, group theory, orbit stabilizer, and wallpaper symmetries activities. The standalone Chapter Zero Vite app is in [`interactive-artin-ch0/`](interactive-artin-ch0/).

GitHub Actions builds and deploys the site to GitHub Pages when either app changes on `main`.
